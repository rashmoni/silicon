# Silicon

Responsiv landing page byggd med HTML och CSS utifrån en Figma-design. Grupparbete.

## Sektioner

| Sektion | Beskrivning | Ansvarig |
| --- | --- | --- |
| Header | Logotyp, Dark Mode-växel och Sign in / up | Rashmoni Dey |
| Hero | Rubrik, introtext, App Store / Google Play och telefonbild | Rashmoni Dey |
| Features | Varumärkeslogotyper, App Features och feature-kort | Jon Larsen |
| How Does It Work | Telefonkarusell och beskrivning av hur appen fungerar | Jon Larsen |

Dark mode (CSS-variabler och theme toggle) ingår i header/hero och är implementerat av Rashmoni Dey.

Rashmonis sektioner **Header** och **Hero** ligger på 'main'.
Jons sektioner **Features** och **How Does It Work** ligger på `main`.

## Teknik

- HTML
- CSS (custom properties, nesting, media queries)
- JavaScript för dark mode-växeln
